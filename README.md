# Extensão de Automação para Envio de Tutoriais APN

## Objetivo do Projeto

Este projeto consiste em uma extensão desenvolvida para otimizar o processo de envio de tutoriais APN para clientes da Vero. O objetivo foi automatizar uma atividade que era realizada manualmente pelos atendentes, reduzindo o tempo de atendimento, diminuindo erros de preenchimento e garantindo maior padronização na comunicação com os clientes.

## Tecnologias Utilizadas

* HTML
* CSS
* JavaScript
* APIs do navegador para extensões
* Outlook Web (integração para criação automática de e-mails)

## O que Foi Aprendido

Durante o desenvolvimento deste projeto, foram adquiridos conhecimentos práticos sobre:

* Desenvolvimento de extensões para navegador.
* Manipulação do DOM e automação de tarefas repetitivas.
* Integração entre sistemas web e serviços externos.
* Testes, validação e correção de falhas em ambiente real.
* Criação de soluções voltadas para ganho de produtividade e melhoria de processos.

## Resultados

A extensão passou por diversas versões de teste e validações internas até chegar à sua primeira versão oficial. Após a implementação, o processo de envio dos tutoriais tornou-se mais rápido e padronizado, contribuindo para uma melhor experiência tanto para os atendentes quanto para os clientes.
